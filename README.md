# Homebrew Tap

Custom Homebrew formulas by NewTurn2017

## Installation

```bash
brew tap NewTurn2017/tap
```

## Available Formulas

### remove-gemini-logo

AI 생성 이미지에서 Gemini 로고를 배치 제거하는 맥 앱

```bash
brew install remove-gemini-logo
remove-gemini-logo
```

### stopcat

필요 없는 것만 멈추는 맥 정리 도구. 프로젝트·AI 세션 단위로 누가 왜 띄웠는지 보여 주고, 확인 뒤에만 정리합니다.

```bash
brew install NewTurn2017/tap/stopcat
stopcat
```
